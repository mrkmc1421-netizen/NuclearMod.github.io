NuclearMod VM

The virtual machine that powers NuclearMod.

Purpose

"nuclearmod-vm" will execute Scratch-compatible projects and provide the runtime systems needed by NuclearMod.

Planned systems

- Block execution
- Threads and execution flow
- Sprites and targets
- Variables and lists
- Events and broadcasts
- Clones
- Timers
- Extensions
- Runtime state

Development

The main VM source code will live in "src/".

Tests will live in "test/".
